# 🚀 SamadhanHub

> **Have a problem? Let's solve it together.**

SamadhanHub is a community-driven platform where people can **share problems, discover existing problems, and contribute useful solutions**.

The goal of SamadhanHub is simple: **connect people who have problems with people who can help solve them.**

---

## 🌟 Features

* 📝 **Register a Problem** — Share a problem with the community.
* 🔎 **Browse Problems** — Explore problems posted by other users.
* 💡 **Share Solutions** — Contribute ideas and solutions.
* 👥 **Community Driven** — Connect people who need help with people who can help.
* 🔐 **Login & Profile** — User authentication and profile-related pages.
* 📊 **Community Statistics** — Display registered problems, solved problems, and shared solutions.
* 📱 **Responsive Design** — Designed to work across different screen sizes.
* 🎨 **Clean UI** — Simple and modern interface focused on usability.

## The homepage currently includes navigation for **Home, Browse Problems, Register Problem, and Login**, along with community statistics and recently registered problems.

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/SamadhanHub.git
```

### 2. Open the project

```bash
cd SamadhanHub
```

### 3. Run the website

Because this is currently a frontend project, you can open:

```text
index.html
```

directly in your browser.

For development, you can also use **VS Code + Live Server**.

---

## 🚀 Using VS Code

1. Open **VS Code**
2. Select **File → Open Folder**
3. Select the `SamadhanHub` folder
4. Install the **Live Server** extension
5. Right-click `index.html`
6. Select **Open with Live Server**

Your website should open in the browser.

## 📊 Community

SamadhanHub is designed around three core community metrics:

| Metric                 | Description                            |
| ---------------------- | -------------------------------------- |
| 📝 Problems Registered | Problems submitted by users            |
| ✅ Problems Solved      | Problems that received a solution      |
| 💡 Solutions Shared    | Solutions contributed by the community |

The current homepage displays these statistics dynamically as part of the platform's community section.
